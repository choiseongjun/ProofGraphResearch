# 성능 측정 가이드

대시보드에서 완료한 작업은 `Quality gate`에 전체 소요 시간, Provider, 모델을 표시한다. `GET /v1/metrics/summary` API는 최근 100개 완료 작업의 평균 소요 시간과 평균 인용 점수를 반환한다.

비교할 때는 같은 주제와 `standard` 깊이를 각각 3회 실행한다.

| Provider / Model | 평균 소요 시간 | 평균 인용 점수 | 관찰 메모 |
|---|---:|---:|---|
| Ollama / qwen3-nothink:4b | 122.8초 (1회 기준) | 27점 (1회 기준) | 로컬, API 비용 없음 |
| OpenAI / 선택 모델 | 측정 후 입력 | 측정 후 입력 | 높은 품질/비용 발생 |

측정값은 대시보드 결과 또는 `/v1/metrics/summary`에서 복사한다. 서로 다른 검색 결과가 영향을 주므로 절대적인 모델 벤치마크가 아니라 서비스 운영 관점의 비교로 해석한다.
